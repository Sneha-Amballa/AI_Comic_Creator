<h1>📘 AI Comic Creator</h1>

<p>
AI Comic Creator is a fun <strong>full-stack project</strong> that transforms any story into 
<strong>comic-style panels</strong> using AI. It automatically breaks a story into scenes,
generates comic images, and exports the result as a downloadable <strong>PDF comic</strong>.
</p>

<hr>

<h2>⭐ Features</h2>

<h3>🎨 Comic Generation</h3>
<ul>
  <li>Converts a <strong>text story</strong> into multiple <strong>comic panels</strong></li>
  <li>Uses AI to <strong>split the story into scenes</strong></li>
  <li>Generates <strong>comic-style images</strong> for each panel</li>
  <li>Displays story + images in a <strong>clean, responsive layout</strong></li>
</ul>

<h3>📄 Output & Downloads</h3>
<ul>
  <li>Exports the final comic as a <strong>PDF</strong></li>
  <li>Fully automated workflow:<br>
      <strong>Story → Panels → Images → PDF</strong>
  </li>
</ul>

<hr>

<h2>🛠️ Tech Stack</h2>

<h3>🎯 Frontend</h3>
<ul>
  <li><strong>React.js</strong></li>
  <li><strong>React Router</strong></li>
  <li><strong>Bootstrap</strong> + Custom CSS</li>
</ul>

<h3>⚙️ Backend</h3>
<ul>
  <li><strong>Node.js</strong></li>
  <li><strong>Express.js</strong></li>
  <li><strong>dotenv</strong></li>
  <li><strong>node-fetch</strong></li>
</ul>

<h3>🤖 AI Models & APIs</h3>
<ul>
  <li><strong>Google Gemini</strong> → Panel text generation</li>
  <li><strong>Stability.ai (schnell model)</strong> → Free comic image generation</li>
</ul>

<h3>📝 PDF Generation</h3>
<ul>
  <li><strong>PDFKit (Node.js)</strong> for generating comic-style PDF pages</li>
</ul>
